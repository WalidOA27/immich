# Detección NSFW (fork mínimo de Immich) — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cola "NSFW Detection" que puntúa cada foto con el cabezal LAION sobre su embedding CLIP, guarda la
puntuación en `asset_metadata`, y un interruptor web Mostrar/Difuminar/Ocultar que la usa en la línea de tiempo.

**Architecture:** Todo ocurre en el servidor de Immich, sin tocar el contenedor de ML ni la base de datos:
un módulo nuevo `server/src/nsfw/` calcula la puntuación (MLP de 18.500 parámetros en TypeScript), un
servicio nuevo copia el patrón de la detección de duplicados, y la consulta de buckets añade una columna
`isNsfw` y un filtro `withoutNsfw`. La web lee la columna y guarda el modo en localStorage.

**Tech Stack:** NestJS + Kysely + Zod (server), SvelteKit + Svelte 5 (web), vitest, Postgres de testcontainers
(tests medium), mise (toolchain fijada por Immich), Docker (imagen del servidor).

**Spec:** `docs/superpowers/specs/2026-11-08-nsfw-design.md`

## Global Constraints

- Base: tag `v3.3.6`; rama `nsfw`; remotos `origin` = `WalidOA27/immich`, `upstream` = `immich-app/immich`.
- **Ninguna migración** nueva, ninguna tabla nueva, ningún cambio en `machine-learning/`.
- Código nuevo en ficheros nuevos siempre que se pueda; en ficheros de Immich, el mínimo de líneas.
- Metadata: clave `nsfw`, valor exacto `{ "score": <number 0–1>, "model": "laion-clip-b32", "v": 1 }`.
- Modelo CLIP soportado: solo `ViT-B-32__openai` (embedding de 512). Con otro, el job devuelve `Skipped`.
- Umbral: variable de entorno `IMMICH_NSFW_THRESHOLD`, por defecto `0.5`; una foto es NSFW si `score >= umbral`.
- Modo web: valores `'show' | 'blur' | 'hide'`, clave localStorage `nsfw-mode`, por defecto `'show'`.
- Ficheros generados (`open-api/immich-openapi-specs.json`, `packages/sdk/src/fetch-client.ts`,
  `server/src/queries/*.sql`) se regeneran con las herramientas, nunca se editan a mano.
- Commits con el pie `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Metadata `nsfw` mal formada (la API pública acepta cualquier clave: `score` como texto, ausente o `null`)
   → la línea de tiempo no debe dar error 500; esa foto cuenta como no NSFW. *(Test en Task 3.)*
2. `IMMICH_NSFW_THRESHOLD` inválido (`abc`, `-1`, `2`, vacío) → se usa `0.5` y se avisa una vez en el log.
   *(Test en Task 1.)*
3. Modelo CLIP distinto de ViT-B-32 o embedding con otra dimensión → el job se salta, no falla en bucle ni
   guarda basura. *(Test en Task 2.)*
4. Modo Ocultar: el recuento de cada mes (`getTimeBuckets`) debe coincidir con las fotos devueltas
   (`getTimeBucket`); si no, la línea de tiempo deja huecos o meses vacíos. *(Test en Task 3.)*
5. Smart Search se vuelve a ejecutar para una foto (embedding nuevo) → la puntuación NSFW se recalcula aunque
   ya existiera. *(Test en Task 2.)*

  - `it('parses pgvector text')`: `parseEmbedding('[1,2.5,-3]')` → `Float32Array [1, 2.5, -3]`.
  - `it('reads the threshold from the environment')`: `{ IMMICH_NSFW_THRESHOLD: '0.37' }` → `0.37`;

- [ ] **Step 2:** `cd server && mise exec -- pnpm test -- src/nsfw` → FAIL (módulo no existe).
- [ ] **Step 3: Implementar `nsfw.ts`.** Decodificar cada blob base64 de `LAION_CLIP_B32` a `Float32Array`
  una sola vez (perezoso, al primer uso). Kernels en orden fila-mayor `[in, out]` (forma de Keras). Cálculo:

  ```
  n[i]  = (x[i] - mean[i]) / sqrt(max(variance[i], 1e-7))
  h1    = relu(n · dense1Kernel + dense1Bias)      // 512 → 32
  h2    = relu(h1 · dense2Kernel + dense2Bias)     // 32 → 32
  score = sigmoid(h2 · dense3Kernel + dense3Bias)  // 32 → 1
  ```
  Acumular en `number` (float64). `getNsfwThreshold`: `Number(value)`; si no es finito o está fuera de
  `[0, 1]`, devolver `DEFAULT_NSFW_THRESHOLD` (el aviso en log lo hace quien la llama, Task 2/3).
